# Facturation — application Android (bêta de test)

Application Android d'un assistant de facturation médicale, **version de test : données fictives seulement**.
Projet indépendant, sans lien avec la RAMQ.

## Installer

Téléchargez [Facturation.apk](https://github.com/Themauritian1996/facturation-clinique-app/releases/latest/download/Facturation.apk) sur un téléphone Android, puis ouvrez le fichier.

La même application est accessible dans un navigateur : https://facturation-clinique-beta.web.app
