# Facturation — application Android

Assistant de facturation à l'acte pour médecins spécialistes du Québec. Chaque médecin a son propre espace.
Projet indépendant, sans lien avec la RAMQ : l'application prépare les réclamations, la saisie à la RAMQ reste faite par le médecin.

## Installer

Téléchargez [Facturation.apk](https://github.com/Themauritian1996/facturation-clinique-app/releases/latest/download/Facturation.apk) sur un téléphone Android, puis ouvrez le fichier.

Sur iPhone ou sur un ordinateur, utilisez le site : https://facturation-clinique.web.app

## Données

Les données sont hébergées chez Google (Firebase, région de Montréal) et les documents sont lus par Gemini (Google).
