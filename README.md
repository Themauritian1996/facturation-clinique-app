# Facturation — application Android

Coquille Android d'un assistant de facturation médicale **hébergé localement** dans une clinique.

- Cette application ne contient **aucune donnée** : au premier lancement, elle demande l'adresse du serveur de la clinique, puis l'ouvre.
- Sans ce serveur (privé), elle ne sert à rien.
- Projet indépendant, sans lien avec la RAMQ.

## Installer

Téléchargez [Facturation.apk](https://github.com/Themauritian1996/facturation-clinique-app/releases/latest/download/Facturation.apk) sur un téléphone Android, puis ouvrez le fichier.
